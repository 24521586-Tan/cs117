Tạo Integration: Truy cập developers.notion.com, tạo một integration và copy Internal Integration Secret.

Tạo Database: Tạo một Database mới trong Notion (dạng Table) với các cột:

Name (kiểu Title): Tên cuộc họp.

Date (kiểu Date): Ngày diễn ra.

Attendees (kiểu Multi-select): Danh sách người tham gia.

Kết nối: Nhấn nút ... trên Database -> Add connections -> Chọn Integration bạn vừa tạo.

Lấy ID: Copy Database ID từ URL.

Hướng dẫn tạo Notion Database

Bước 1: Tạo Database mới trong Notion
Mở Notion và tạo một trang trống (Add a page).
Gõ /database vào trang và chọn Database - Inline hoặc Database - Full page (nên chọn Full page để có không gian rộng rãi, dễ nhìn).Đặt tên cho Database của bạn (ví dụ: Meeting Notes).

Bước 2: Thiết lập các cột (Properties)
Để khớp với đoạn code Python mẫu, bạn cần thiết lập 3 cột với đúng kiểu dữ liệu:
Cột 1 (Tên cuộc họp): Cột đầu tiên mặc định luôn mang kiểu dữ liệu Title (biểu tượng Aa) và thường có tên là Name. Bạn có thể giữ nguyên tên này.
Cột 2 (Ngày tháng): Nhấp vào tiêu đề của cột thứ 2 (thường tên là Tags) $\rightarrow$ Chọn Edit property $\rightarrow$ Đổi Type (kiểu dữ liệu) thành Date và đổi tên cột thành Date.
Cột 3 (Người tham gia): Nhấp vào dấu + ở góc phải bảng để thêm cột mới $\rightarrow$ Đặt tên là Attendees $\rightarrow$ Chọn Type là Multi-select.

Bước 3: Cấp quyền cho Integration (Bước cực kỳ quan trọng)Mặc định, API không có quyền truy cập vào các trang cá nhân của bạn. Nếu bỏ qua bước này, API sẽ trả về lỗi 404 Object Not Found.
Nhìn lên góc trên cùng bên phải của trang Database, nhấn vào biểu tượng 3 dấu chấm (...).
Kéo xuống dưới cùng của menu, chọn Add connections.
Khung tìm kiếm hiện ra, gõ tên Integration mà bạn đã tạo trên trang Notion Developers.
Nhấn chọn Integration đó và xác nhận Confirm.

Bước 4: Lấy Database ID để dán vào code
Nếu bạn đang dùng Notion trên trình duyệt: Nhìn lên thanh địa chỉ URL.
Nếu bạn dùng ứng dụng Notion: Nhấn nút Share ở góc trên bên phải $\rightarrow$ Chọn Copy link.
Đường link bạn vừa copy sẽ có định dạng tương tự như sau:https://www.notion.so/workspace_name/abc123def45678901234567890abcdef?v=...Đoạn mã gồm 32 ký tự chữ và số nằm trước dấu ? chính là Database ID của bạn (trong ví dụ trên là abc123def45678901234567890abcdef).
Copy chuỗi ID này và thay vào biến DATABASE_ID trong file code Python của bạn.
